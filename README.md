# Midpoint

## The truth is rarely at the edges.

<sub><i>Nobody is entirely right. The truth usually lives somewhere in between.</i></sub>

Midpoint helps people work through personal conflicts and misunderstandings calmly and fairly. Describe an issue in a sentence or two, answer a few short questions, and get private, unbiased AI advice. That includes honest feedback when you're part of the problem, without making you feel judged. When you're ready, Midpoint can help you raise the issue with the other person as a polite message and keep the conversation on track in a mediated thread, so you both meet somewhere in the middle.
